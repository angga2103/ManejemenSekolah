# Web Administrative Portal & Control Center

Web frontend for the **Integrated School & Pesantren Management SaaS** platform.

## Technologies
- **React 18** (Vite bundler)
- **TypeScript 5**
- **Tailwind CSS 3**
- **TanStack Query & Table**
- **Lucide React Icons**

## Structure
- `src/components/`: Reusable UI design system components
- `src/pages/admin/`: Institutional administration portals
- `src/pages/dev-center/`: SaaS multi-tenant Developer Control Center
- `src/services/`: API integration clients using `@edusaas/api-contracts`
